# Planning Documents

Documents describing the hardware-detached agent runtime and the economic machine built around it.

| Document | What it covers |
|---|---|
| [Hardware-Detached Agent Runtime Roadmap](AGENT_RUNTIME_ROADMAP.md) | Staged build plan (Stages 0–8) for suspending an agent into a signed capsule, destroying its runtime, and restoring it through a stable SSH identity. Includes fundraising gates, metrics, and deferred features. |
| [The Four-System Pipe](AGENT_ECONOMY_ARCHITECTURE.md) | Combines the runtime with a compute resolver, proof network, and settlement engine into one protocol with four authorities: continuity, embodiment, truth, and value. |
| [EvidencePipe](EVIDENCEPIPE.md) | A $300K pre-seed verification ETL company: turn "the tests passed" into portable, independently verifiable proof, with digest-bound human approval before any external action. |
| [Proof-of-Answer](PROOF_OF_ANSWER.md) | The receipt-backed outcome primitive that lets a durable agent identity earn revenue for verified intellectual work while its compute providers change. |

Reading order: roadmap → four-system pipe → EvidencePipe → Proof-of-Answer.
